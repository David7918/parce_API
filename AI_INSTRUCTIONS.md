# AI Development Instructions

## General Rules

- Read PROJECT.md before making changes.
- Read REQUIREMENTS.md before implementing features.
- Read ARCHITECTURE.md before modifying architecture.
- Read DECISIONS.md before proposing architectural changes.
- Check TASKS.md to determine the current task.

## Development Process

1. Explain your proposed approach.
2. Make the smallest reasonable change.
3. Run tests.
4. Review the resulting code.
5. Report what changed and what was tested.

## Do Not

- Rewrite working code unnecessarily.
- Introduce new dependencies without explaining why.
- Change architectural decisions without discussing them first.
- Delete tests to make a test suite pass.
- Hard-code API keys or other secrets.
- Implement features that aren't in the requirements.

## Code Quality

Prefer:

- Simple code
- Small functions
- Clear names
- Explicit error handling
- Minimal dependencies
